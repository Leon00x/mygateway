## 已退役的 ChatGPT Plus / Codex 订阅反代实验

项目曾实验通过用户订阅会话向网关提供 API。该路径无法在 Cloudflare Worker 出口稳定工作，
并且会引入 OAuth 凭据、安全边界和上游兼容性风险，因此相关控制台、路由适配与测试已经移除。
已发布 migration 保持不可变，后续 migration 负责清理实验凭据和资源。

这段历史不能被解释为已支持或规划中的产品能力；如未来重新评估，应作为新的产品提案进入 PRD。
