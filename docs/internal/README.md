# 内部维护记录

本目录只保存维护者在开发过程中可能需要追溯、但不属于开源产品契约的材料，例如一次性生产
验证、已放弃实验、临时排障结论和特定环境记录。

- 产品范围和状态以 [PRD](../PRD.md) 为准。
- 可复用部署步骤以[部署指南](../DEPLOY.md)为准。
- 可复用验证方法以[测试指南](../TESTING.md)为准。
- 本目录不得成为构建、测试、部署或 Agent 接续开发的依赖。
- 发布公共源码包时可以删除整个目录，不影响功能和文档闭环。

当前归档见[开发历史](DEVELOPMENT_HISTORY.md)。新记录应先判断是否能转化为长期规则；能转化的
内容写入相应公开文档，只把环境快照和过程证据留在这里。
